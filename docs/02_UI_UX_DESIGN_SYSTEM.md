# DJO COIFFE

# UI / UX DESIGN SYSTEM

Version 1.0

---

# OBJECTIVE

The user interface must feel like a premium mobile application.

The inspiration should come from:

• Apple Human Interface Guidelines

• Airbnb

• Stripe

• Notion

• Uber

• Booksy

Avoid old-fashioned administration interfaces.

Avoid Bootstrap-like appearance.

Avoid clutter.

The interface should communicate luxury, cleanliness and professionalism.

---

# DESIGN PHILOSOPHY

Every screen must answer one question:

"What is the most important action on this screen?"

Everything else becomes secondary.

Users should never hesitate.

The application should require almost no learning.
