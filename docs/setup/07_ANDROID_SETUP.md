# Android Setup

Djo Coiffe uses Capacitor to wrap the web application into a native Android APK.

## 1. Prerequisites
Ensure you have installed Android Studio and the Java JDK 17 as outlined in `01_PREREQUISITES.md`.

## 2. Syncing the Web App to Android
Capacitor works by running your built web application (`dist/`) inside a native WebView. Every time you make changes to your React code, you must rebuild and sync:
```bash
npm run build
npm run cap:sync
```

## 3. Opening Android Studio
Open the Android project generated by Capacitor:
```bash
npm run cap:android
```
Android Studio will launch. Wait for Gradle to finish syncing (watch the progress bar at the bottom right).

## 4. Setting up an Emulator or USB Debugging
- **Emulator**: In Android Studio, go to **Tools > Device Manager** and click **Create Device**. Follow the wizard to create a Pixel device with API 34.
- **Physical Device**: Enable **Developer Options** and **USB Debugging** on your Android phone. Connect it via USB.

Click the green **Play** button in Android Studio to run the app on your selected device.

## 5. Generating a Release APK
When you are ready to distribute the app outside the Play Store, generate a signed APK.

1. In Android Studio, go to **Build > Generate Signed Bundle / APK**.
2. Select **APK** and click Next.
3. Under **Key store path**, click **Create new...**
   - Save it somewhere secure (e.g., `C:\keystores\djocoiffe.jks`).
   - Create strong passwords and fill out the certificate details.
4. Click Next. Select **release** as the Build Variant.
5. Click **Finish**.

### Where is the APK located?
Once the build succeeds, click "locate" in the notification popup, or navigate to:
`barber/android/app/release/app-release.apk`

## 6. Common Android Errors

**Error:** `JAVA_HOME is not set or points to an invalid JDK.`
**Fix:** Set the `JAVA_HOME` environment variable to your JDK 17 installation path.

**Error:** `Could not resolve all dependencies for configuration ':app:debugRuntimeClasspath'.`
**Fix:** Usually caused by network issues or outdated Gradle caches. Go to **File > Invalidate Caches / Restart** in Android Studio.

**Error:** Camera permissions crashing the app.
**Fix:** Capacitor automatically merges permissions from `capacitor.config.ts` plugins, but if testing purely on web-emulator, ensure you grant the camera permission in the Android Settings app for Djo Coiffe.
