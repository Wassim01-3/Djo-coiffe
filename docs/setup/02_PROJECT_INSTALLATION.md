# Project Installation

Follow these steps to install and run the Djo Coiffe project locally.

## 1. Clone the Repository
Open your terminal and run the following command to clone the project:
```bash
git clone <repository-url> barber
cd barber
```
*(Open the `barber` folder in VS Code or your preferred IDE).*

## 2. Install Dependencies
The project uses `npm` as its package manager. Install the required Node modules:
```bash
npm install
```
### Why is this required?
This downloads React, Vite, Firebase SDK, Tailwind CSS, Capacitor, and all other libraries defined in `package.json` into the `node_modules` folder.

## 3. Environment Variables
The project requires sensitive keys to connect to Firebase and Cloudinary. 
1. In the root directory, locate the `.env.example` file.
2. Copy it and rename it to `.env`:
   ```bash
   cp .env.example .env
   ```
3. You must fill in the values in the `.env` file before the application will function. (See [05_ENV_CONFIGURATION.md](./05_ENV_CONFIGURATION.md) for detailed instructions on acquiring these keys).

## 4. Folder Overview
Here is a brief overview of the project structure you just cloned:
- `/src`: Contains the entire React application.
  - `/app`: Routing and global Providers.
  - `/components`: Reusable UI components (buttons, cards, dialogs).
  - `/features`: Page-level components organized by domain (home, admin, auth).
  - `/services`: Firebase and Cloudinary logic.
  - `/types`: TypeScript interfaces and type definitions.
- `/docs`: Documentation and architecture guidelines.
- `android/`: The native Android project (generated by Capacitor).
- `vite.config.ts`: Configuration for the Vite bundler and PWA manifest.
- `capacitor.config.ts`: Configuration for Android packaging.

## 5. Verify Installation and Start Development
To verify that everything is installed correctly, start the development server:
```bash
npm run dev
```

### Expected Output
```
  VITE v8.2.0  ready in 1500 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h to show help
```

### Verification
Open `http://localhost:5173/` in Google Chrome. You should see the Djo Coiffe splash screen followed by the Home Page. Note: If Firebase is not configured yet, the app will throw console errors related to initialization.
